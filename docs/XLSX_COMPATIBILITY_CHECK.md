# XLSX compatibility check

This procedure tests the supported XLSX subset with invented data. It does not use customer workbooks, personal information, or private business records.

## What the generated fixture contains

The `community_budget_compatibility_fixture` creates a small community-event budget with:

- Two worksheets whose order is resolved through OOXML relationship IDs
- Text, numbers, direct cell formatting, number formats, local formulas, and a quoted cross-sheet formula
- List and decimal validation rules
- A cell-value conditional-format rule with font and fill colors

The fixture is generated by 900Sheets. Call it an Excel-compatible fixture, not an Excel-saved fixture. Microsoft Excel has not produced or approved it.

Generate a fresh copy outside the repository:

```bash
cargo run -p sheets-xlsx --example generate_compat -- /tmp/900sheets-community-budget.xlsx
```

Run the deterministic crate checks first:

```bash
cargo test -p sheets-xlsx
```

When LibreOffice is installed, the external test opens and re-saves the same generated data, then verifies cells, formulas, direct formatting, validation, and the supported conditional-format rule.

## Manual Microsoft Excel procedure

Use a fresh generated fixture for each check. Never overwrite the source fixture.

1. Record the date, operating system, and exact Excel version.
2. Generate `/tmp/900sheets-community-budget.xlsx` with the command above.
3. Open the file in Microsoft Excel. Record any repair, compatibility, or security warning before continuing.
4. Confirm that `Community Budget` appears before `Assumptions`.
5. Confirm that the blue header style, percentage number format, totals, difference formulas, and projected-contingency cross-sheet formula are present.
6. Confirm that cells `A2:A4` on `Community Budget` offer the category list and that `B2` on `Assumptions` accepts values from 0 through 0.25.
7. Confirm that a negative value in `D2:D4` receives the configured red conditional format.
8. Change `Community Budget!C2` from `1180` to `1175` and add `Excel manual check` to `A7`.
9. Save As `/tmp/900sheets-community-budget-excel-resaved.xlsx` in XLSX format.
10. Close Excel, reopen the saved file in Excel, and repeat steps 4 through 7.
11. Open the Excel-resaved file in 900Sheets. Confirm the changed value, marker text, formulas, supported direct styles, validation rules, and supported conditional format.
12. Export the workbook from 900Sheets to a third filename, reopen it in Excel, and repeat steps 4 through 7.

Record each result as Pass, Fail, or Not checked. A warning, repaired-record message, missing rule, or changed formula is a failure and should include the exact message and affected cell or range. Do not broaden a passing result beyond the tested Excel version and platform.

## Supported feature records

The typed `XlsxDocument` API carries supported worksheet metadata alongside the workbook. `import_document` and `export_document` currently map:

- Whole-number, decimal, list, date, time, text-length, and custom validation records
- Validation formulas, prompts, error messages, dropdown behavior, blank behavior, operators, and error styles
- Cell-value, formula, text contains, text does not contain, text begins with, text ends with, blanks, nonblanks, and duplicate-value conditional-format rules
- Differential font, fill, border, and number-format properties used by those rules
- Multiple `sqref` ranges as separate sheet-scoped rules

The original `import_workbook` and `export_workbook` helpers remain cell-and-direct-style APIs. The desktop commands use the document API and map each feature vector to the stable identity of the relationship-selected sheet. The `xlsx_features_follow_imported_sheet_stable_ids` desktop regression covers that boundary.

Malformed XML is still bounded by the XLSX entry-size limit. Combined imported validation and conditional-format ranges are limited to 100,000 records per workbook, and a single `sqref` list is stopped at that same limit before it can grow without bound.

## Deferred XLSX objects

The following remain deferred and must not be described as preserved:

- Native Excel charts and pivot caches
- Macros and VBA projects
- Images, shapes, and embedded objects
- External workbook links
- Tables and slicers
- Conditional formats outside the supported set, including color scales, data bars, icon sets, top or bottom rules, average rules, errors, no-errors rules, and unique-value rules
- Theme, indexed, and automatic colors that do not contain a direct RGB value

Keep the original workbook when testing files that contain unsupported records. XLSX export is not a lossless pass-through for those objects.

The typed exporter rejects unsupported 900Sheets conditional-format types and invalid range mappings instead of silently omitting them.
